# Lesson 09 — Tonality, Modes, Special Scales

## 목표
Major/Minor를 넘어 tonal center와 mode의 관계를 이해하고, scale 선택을 실제 melody/harmony color와 연결한다.

## 1. Tonality
Tonality는 단순히 사용 음 목록이 아니라 어떤 pitch/chord가 중심으로 느껴지고 다른 음이 그 중심과 어떤 관계를 만드는지 포함한다.

## 2. Major / Minor
Major와 Natural/Harmonic/Melodic Minor를 비교하고 특히 scale degree 변화가 dominant tendency와 melody color를 어떻게 바꾸는지 듣는다.

## 3. Modes
Ionian/Dorian/Phrygian/Lydian/Mixolydian/Aeolian/Locrian을 이름 순서로만 외우지 않는다. 같은 tonic을 유지한 parallel comparison으로 characteristic degree를 듣는다.

예:
```text
C Ionian  vs C Lydian  → 4 vs #4
C Ionian  vs C Mixolydian → 7 vs b7
C Aeolian vs C Dorian → b6 vs 6
```

## 4. Special Scales
Pentatonic, blues, whole-tone, diminished 등 자주 만나는 scale을 `어떤 음정 구조와 color를 만드는가` 관점으로 공부한다. 모든 scale을 한 번에 암기하지 않는다.

## 5. Melody 실습
같은 tonic drone/ostinato 위에서 4마디 melody를 세 버전 만든다.

```text
A: major/minor baseline
B: mode characteristic note 강조
C: pentatonic 또는 다른 selected scale
```

## 6. Harmony 실습
Mode를 쓸 때도 chord progression이 tonal center를 무너뜨리지 않는지 듣는다. 단순히 scale note를 모두 사용했다고 modal music이 되는 것은 아니다.

## 완료 체크
- [ ] tonality와 scale을 구분한다.
- [ ] parallel mode 비교를 했다.
- [ ] characteristic degree를 귀로 찾았다.
- [ ] special scale 하나를 실제 phrase에 사용했다.
