# Lesson 03 — Chord Function과 Progression: 안정, 이동, 긴장을 설계한다

## 학습 목표
- Tonic, Predominant, Dominant 기능을 구분한다.
- 진행을 감정의 방향으로 듣는다.
- Verse와 Chorus의 화성 역할을 비교한다.

## 1. 기능으로 듣기
기초 단계에서는 코드를 세 가지 큰 역할로 묶어 듣는다.

```text
Tonic       = 안정, 귀환점
Predominant = 이동, 전개, Dominant 준비
Dominant    = 긴장, Tonic으로 향하는 힘
```

전형적인 흐름은 `T → PD → D → T`다. 모든 Pop 진행이 이 순서를 그대로 따르는 것은 아니지만 긴장과 해결을 분석하는 좋은 출발점이다.

## 2. 진행을 외우지 말고 방향을 듣기
`I–V–vi–IV`처럼 자주 쓰는 진행도 Tempo, Bass, Voicing, Melody, Harmonic Rhythm에 따라 인상이 달라진다. 진행 이름을 외운 뒤 반드시 실제로 연주한다.

## 3. Section별 기능
Verse에서는 반복 가능한 안정감을 유지하고 Pre-Chorus에서 Dominant 성격이나 불안정성을 키운 뒤 Chorus에서 해결감을 줄 수 있다. 반대로 Chorus를 의도적으로 열린 상태로 끝낼 수도 있다.

## 4. 직접 작곡
