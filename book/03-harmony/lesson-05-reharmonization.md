# Lesson 05 — Reharmonization: 같은 멜로디의 감정을 바꾼다

## 학습 목표
- 기본 진행을 유지한 채 일부 화성을 교체한다.
- Secondary Dominant, Related IIm7, Tritone Substitution, Modal Interchange의 **기초 목적과 청감 차이**를 이해한다.
- 복잡함 자체가 목표가 아님을 익힌다.

> 이 Lesson은 개념 입문이다. Guide Tone, Substitute ii–V, Altered Tension, Subdominant Minor 등 재즈 화성학의 세부 적용은 Part 17에서 심화한다.

## 1. Reharmonization의 목적
리하모니는 어려운 코드를 많이 쓰는 기술이 아니다. **같은 멜로디와 구조에 다른 긴장·색채·진행 방향을 부여하는 방법**이다.

## 2. Secondary Dominant
C Major에서:

```text
C → A7 → Dm → G → C
```

A7은 Dm을 잠시 목표처럼 들리게 한다. 핵심은 `왜 A7인가`를 목표 코드와의 Dominant 관계로 이해하는 것이다.

## 3. Related IIm7
Secondary Dominant 앞에 관련 ii를 배치해 ii–V 움직임을 만든다. 재즈 문법에서 흔하지만 Pop/R&B/Ballad에서도 색채를 줄 수 있다. 이 단계에서는 목표 코드와 ii–V의 연결만 확인하고, substitute ii–V 같은 확장 문법은 Part 17에서 다룬다.

## 4. Tritone Substitution
Dominant 계열의 긴장 성분을 공유하는 증4도 관계의 Dominant로 대체해 Bass movement와 색채를 바꿀 수 있다. 여기서는 원래 Dominant와 대체 Dominant를 번갈아 연주해 차이를 듣는 데 집중한다.

Guide Tone 공유, chromatic bass, substitute ii–V의 세부 구조는 [Part 17 Lesson 15](../17-applied-jazz-harmony/lesson-15-tritone-sub-ii-v.md)에서 심화한다.

## 5. Modal Interchange
평행조에서 코드를 빌린다. C Major에서 iv인 Fm을 빌리는 식으로 예상 밖의 감정 전환을 만들 수 있다.

Subdominant Minor 계열의 세부 기능과 Tonic Substitution은 [Part 17 Lesson 02](../17-applied-jazz-harmony/lesson-02-subdominant-minor-tonic-substitute.md)에서 심화한다.

## 6. Modulation과 구분
Borrowed chord 하나를 사용했다고 반드시 Key가 바뀐 것은 아니다. 새로운 중심이 충분히 확립될 때 Modulation으로 본다.

## 7. 실습
기본 진행 하나를 정한다.

```text
Original:
Version A — Secondary Dominant:
Version B — Modal Interchange:
Version C — Inversion only:
```

평가:
```text
Most natural:
Most emotional:
Most surprising:
Best for Verse:
Best for Pre-Chorus:
Best for Chorus:
```

## 8. AI 음악과 연결
AI가 복잡한 코드를 생성했다고 좋은 곡은 아니다. Candidate를 비교할 때는 `화성이 Section의 목적에 기여했는가`, `멜로디를 방해하지 않는가`, `과도한 변화가 Hook 기억을 해치지 않는가`를 듣는다.
