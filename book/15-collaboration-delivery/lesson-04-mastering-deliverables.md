# Lesson 04 — Mastering Handoff와 Deliverables

## 목표
Mastering 단계에 필요한 Mix와 최종 배포 파일을 혼동하지 않는다.

## 1. Mastering에 전달할 Mix

```text
Final approved mix
No accidental clipping
Correct sample rate / bit depth
No unnecessary final limiter unless it is part of the intended sound
Reference tracks
Track title / version
Notes about fades, sequencing, special requirements
```

Limiter를 제거할지 유지할지는 Mastering Engineer와 협의한다. 고정된 한 가지 공식으로 취급하지 않는다.

## 2. 승인된 Mix 고정
Mastering을 시작한 뒤 Arrangement나 Vocal edit가 바뀌면 새로운 Mix version이다. 같은 파일명으로 덮어쓰지 않는다.

## 3. 최종 Deliverables
프로젝트 목적에 따라 다음 결과물이 필요할 수 있다.

- Master WAV
- Instrumental
- Acapella
- TV Mix
- Stems
- Preview
- MP3/AAC reference copy

모든 프로젝트가 전부 필요하지는 않다.

## 4. Metadata

```text
Title:
Artist / project:
Version:
Composer:
Lyricist:
Arranger:
Producer:
Mix:
Master:
BPM:
Key:
ISRC if assigned:
Rights notes:
```

## 5. Final QC
최종 파일을 처음부터 끝까지 듣는다.

```text
Correct song/version?
Start/end clean?
Unexpected noise?
Clipping/distortion?
Metadata correct?
File opens and plays?
Deliverable naming correct?
```

## DohaStudio 연결
Export Artifact는 어떤 Snapshot/Mix에서 만들어졌는지 lineage를 남기는 것이 중요하다. 최종 WAV와 작업 중 WAV를 같은 의미의 Artifact로 다루지 않는다.

## 완료 체크
- [ ] Mastering 전달 Mix를 준비할 수 있다.
- [ ] 필요한 Deliverable을 프로젝트별로 선택한다.
- [ ] Final QC를 수행한다.
