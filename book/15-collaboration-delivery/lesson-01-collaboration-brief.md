# Lesson 01 — 협업 시작 전 Brief

## 목표
작업을 시작하기 전에 음악 목표, 역할, 일정, 파일 규칙, 권리 범위를 합의한다.

## 1. 최소 Brief

```text
Project title:
Goal:
Genre / mood:
Reference tracks:
BPM / key:
Song form:
Deadline:
My role:
Collaborator role:
Expected deliverables:
File format:
Revision rounds:
Commercial use expected?:
Credit / split discussion status:
```

## 2. Reference 전달
레퍼런스 곡은 '똑같이 만들어 달라'가 아니라 무엇을 참고하는지 구체적으로 쓴다.

```text
Reference A: chorus energy
Reference B: drum texture
Reference C: vocal intimacy
```

## 3. 역할 구분
작곡, 편곡, 작사, 보컬 디렉팅, 녹음, 편집, Mix, Master를 한 단어 `프로듀싱`으로 뭉개지 않는다.

## 4. 수정 범위
무제한 수정이라는 표현 대신 무엇을 몇 번까지 검토하는지 작업 전에 정한다. 개인 연습에서는 이 구조를 익히는 것만으로 충분하다.

## DohaStudio 연결
Project와 Job identity는 작업 의도와 결과의 관계를 추적하는 기반이 된다. 미래 협업 기능이 생기더라도 음악 Brief 자체는 사람이 읽을 수 있는 형태로 남기는 것이 좋다.

## 완료 체크
- [ ] 협업 Brief를 한 번 작성했다.
- [ ] Reference마다 참고 요소를 분리했다.
- [ ] 역할과 Deliverable을 적었다.
