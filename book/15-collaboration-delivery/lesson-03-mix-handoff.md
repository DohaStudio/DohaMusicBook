# Lesson 03 — Mix Handoff

## 목표
Mix Engineer가 추측하지 않고 작업할 수 있도록 필요한 Audio와 음악적 의도를 전달한다.

## 1. 전달 전 정리

- Clip 시작 위치를 맞춘다.
- 불필요한 muted/unused Track을 제거하거나 별도 보관한다.
- 의도된 Creative Effect인지 임시 Processing인지 구분한다.
- 파일이 clipping되지 않는지 확인한다.
- Track 이름을 의미 있게 정리한다.

## 2. 기본 전달물

```text
Rough mix
Stems or consolidated multitracks
BPM / key
Song structure
Reference tracks + reference purpose
Vocal comp / tuning status
Creative FX that must remain
Mix notes
```

## 3. Stem과 Multitrack
Stem은 여러 Track을 역할별로 합친 파일일 수 있고, Multitrack은 보다 개별적인 소스 단위다. 전달 상대가 무엇을 요구하는지 확인한다.

## 4. Mix Notes

```text
Priority: vocal intimacy, chorus impact
Do not change: intro filtered texture
Problem I hear: bass masks kick in chorus
Reference A: vocal front/back balance
Reference B: low-end weight
```

'좋게 해주세요'보다 음악적 우선순위를 전달한다.

## 5. Print FX 여부
Creative sound의 일부라면 Effect가 적용된 버전과 필요하면 dry 버전을 함께 제공한다. 어떤 것이 의도된 최종 사운드인지 적는다.

## DohaStudio 연결
향후 Export/Stem workflow에서는 어떤 CompositionSnapshot에서 어떤 파일이 생성됐는지 추적할 수 있어야 한다. 현재 완성형 Mix export automation이 있다고 가정하지 않는다.

## 완료 체크
- [ ] Rough Mix와 Mix Notes를 만들었다.
- [ ] Stem/Multitrack 차이를 설명한다.
- [ ] Creative FX의 의도를 표시했다.
