# Lesson 01 — Instrument Role: 악기 이름보다 역할을 먼저 본다

## 학습 목표
- 악기를 Rhythm, Bass, Harmony, Lead, Texture, Transition 역할로 나눈다.
- 같은 악기가 Section마다 다른 역할을 할 수 있음을 이해한다.
- 편곡을 '악기 추가'가 아니라 '역할 배치'로 생각한다.

## 1. 역할 중심으로 듣기
곡을 들을 때 '피아노가 있다'보다 '이 피아노가 지금 무엇을 담당하는가'를 먼저 묻는다.

```text
Rhythm      = 시간의 움직임
Bass        = 저역 중심과 화성의 바닥
Harmony     = 코드/패드/보이싱
Lead        = 가장 주목해야 할 선율
Texture     = 공간과 질감
Transition  = Section을 연결하는 변화 신호
```

## 2. 한 악기, 여러 역할
Piano는 Verse에서 Harmony를 담당하다가 Intro에서는 Lead Motif가 될 수 있다. Guitar도 Rhythm strumming, Counter Melody, Texture 역할을 모두 할 수 있다.

## 3. 충돌을 찾는 질문
- Lead와 경쟁하는 악기가 있는가?
- Bass와 저역 Harmony가 같은 공간을 차지하는가?
- Rhythm 역할이 너무 많아 Pulse가 흐려지는가?
- Texture가 곡의 무드에 기여하는가, 그냥 공간만 채우는가?

## 4. 듣기 실습
좋아하는 곡 한 곡을 Section별로 표로 적는다.

```text
Section | Rhythm | Bass | Harmony | Lead | Texture | Transition
Verse   |        |      |         |      |         |
Pre     |        |      |         |      |         |
Chorus  |        |      |         |      |         |
```

## 5. 직접 편곡
같은 8마디 코드와 멜로디를 다음 두 방식으로 만든다.

- Version A: Piano 하나가 Harmony 대부분 담당
- Version B: Guitar + Pad로 Harmony 역할 분산

무엇이 더 명확한지 기록한다.

## 6. DohaStudio 연결
현재 Track lane은 음악을 읽는 기반으로 활용할 수 있지만 완전한 Track role 편집 기능으로 설명하지 않는다. 향후 `Track.role`, `instrument`, `section_role` 같은 정보가 편곡 분석과 생성 condition에 유용할 수 있다.
