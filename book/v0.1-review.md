## 3. 내용 품질 검수

### 강한 영역

다음 영역은 v0.1에서 바로 공부를 시작할 수 있을 정도로 학습 흐름이 명확하다.

- Song Form: Section role → contrast → listening analysis → DohaStudio Timeline
- Rhythm: Beat/Tempo/Meter → feel → syncopation → groove → section energy
- Harmony: Key/Scale → Diatonic → Function → Harmonic Rhythm → Reharmonization
- Melody: Phrase/Motif → development → contour/range → tension → hook
- AI Music: Reference → condition → candidates → revision → evaluation
- Demo Project: Intent부터 Final/Portfolio까지 End-to-End 기록

### 의도적으로 반복되는 개념

`Section Contrast`, `Energy`, `Candidate Review`, `CURRENT/FOUNDATION/TARGET`은 여러 Part에서 반복된다. 중복 오류가 아니라 동일한 곡을 서로 다른 음악 관점으로 다시 보는 Spiral Learning 구조다.

예:

```text
Song Form   → Section의 역할과 시간 구조
Rhythm      → Section별 groove/energy
Harmony     → Section별 tension/resolution
Melody      → Section별 range/hook
Arrangement → Section별 density/timbre
Mix         → Section별 dynamics/space
```

### v0.1에서 아직 얕은 영역

아래는 병합 blocker가 아니라 실제 공부 과정에서 v0.2+로 깊게 확장할 영역이다.

1. 실제 기성곡 분석 사례
2. 악보/피아노롤/MIDI 예제
3. Ear Training 문제와 정답/해설
4. 장르별 Harmony/Groove/Arrangement 사례
5. 실제 DohaMusic 화면 캡처 기반 walkthrough
6. 실제 DohaStudio source line/file permalink 기반 code lab
7. 실제 SoundFont/Plugin license evidence
8. Mix 전후 Audio A/B 예제
9. 실제 Demo Song 한 곡의 완성 기록

이 항목을 v0.1에 억지로 채우지 않는다. 학습자가 실제로 수행한 결과가 들어가야 가치가 있기 때문이다.

## 5. CURRENT / FOUNDATION / TARGET 검수

- `CURRENT`: 최신 기준 브랜치에서 실제 사용할 수 있는 기능
- `FOUNDATION`: Domain/Contract/Fake/Mock/Runtime 골격은 있으나 최종 제품 기능은 아님
- `TARGET`: 아직 구현되지 않은 목표 기능

특히 다음 기능은 현재 기능으로 오기록하지 않는다.

```text
mutable Track/Clip 완전 편집
MIDI Track / Piano Roll
SoundFont engine integration
완성형 Mixer / Automation
실제 DohaLM / DohaAudio production transport
완성형 Reference Analysis UI
완성형 Composition Evaluation
```

Part 11~12는 DohaStudio 개발 속도 때문에 가장 빨리 낡을 수 있다. 따라서 코드/사용법 Chapter의 상태 설명은 학습 세션을 시작하기 전에 원본 저장소에서 다시 검증한다.

## 6. 저작권 / 출처 검수

DohaMusicBook은 상업 도서의 본문을 복제하지 않는다. 참고 자료에서는 공부해야 할 주제, 일반적인 음악 용어, 학습 범위 아이디어만 사용한다. 설명, 예제, 실습, DohaStudio mapping과 프로그램 사용법은 독립적으로 작성한다.

특정 현존 아티스트/곡의 '스타일 복제법'을 교재 목표로 삼지 않는다. 레퍼런스는 Song Form, Rhythm, Harmony, Melody, Arrangement, Mix 등의 일반적 특성을 분석하는 용도로 사용한다.

## 7. 실제 학습 데이터가 들어갈 자리

v0.1은 빈 책이 아니라 **학습 프레임 + 이론 + 실습 지시서**다. 이후 다음 증거를 축적한다.

- 직접 분석한 곡 기록
- 직접 만든 MIDI/Audio
- 코드 진행·Motif·Groove 연습
- DohaMusic 실행 화면 기반 사용 노트
- AI Candidate A/B
- Demo Song 제작 기록
- Product Gap
- SoundFont/Plugin license evidence
- 최신 DohaStudio 상태 갱신

이 결과는 책 본문과 구분해 `study/`, `examples/`, `labs/` 성격의 기록으로 관리하는 것을 권장한다.
