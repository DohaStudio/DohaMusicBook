# Lesson 06 — Portfolio와 Professional Practice

## 목표
연습 기록과 외부에 보여줄 작품을 구분하고, 완성곡마다 자신의 기여와 제작 과정을 설명할 수 있게 한다.

## 1. 모든 연습곡이 Portfolio는 아니다
Study와 Portfolio를 분리한다.

```text
Study = 실패와 시행착오까지 보존
Portfolio = 목적에 맞게 선별한 완성 결과
```

## 2. Portfolio Entry

```text
Title:
Completion date:
Role:
Genre:
Length:
Music intent:
Human-written parts:
AI-assisted parts:
Manual revisions:
Tools:
Mix/master:
Rights check:
What this demonstrates:
```

## 3. 작곡가 설명 능력
곡을 들려준 뒤 다음 질문에 답할 수 있어야 한다.

- 왜 이 Song Form인가?
- Chorus Hook은 무엇인가?
- Verse와 Chorus를 어떻게 대비시켰는가?
- 코드/리듬/편곡에서 핵심 결정은 무엇인가?
- AI가 만든 부분 중 무엇을 거절했는가?
- 사람이 무엇을 수정했는가?

## 4. Version 보존
최종 파일 하나만 남기지 않는다.

```text
v0 idea
v1 selected candidate
v2 human edit
v3 mix
v4 master/final
```

변경 이유를 기록한다.

## 5. 권리와 Credit
외부에 공개할 작품은 Part 10 Rights checklist를 통과한 것만 Portfolio 후보로 둔다. 공동 작업이 있다면 기여 역할을 정확히 기록한다.

## 6. DohaStudio Portfolio 가치
DohaStudio 자체도 Portfolio의 일부가 될 수 있지만 'AI가 대신 작곡한다'는 설명보다 다음을 보여주는 것이 중요하다.

```text
음악적 Intent를 구조화한다.
여러 후보를 생성하고 평가한다.
사람이 수정할 수 있는 제작 흐름을 만든다.
권리와 lineage를 보존한다.
최종 음악적 결정은 사람이 한다.
```

## 완료 기준
- [ ] Study와 Portfolio를 구분한다.
- [ ] 완성곡의 자신의 기여를 설명한다.
- [ ] Version history를 남긴다.
- [ ] 공개 전 Rights check를 수행한다.
