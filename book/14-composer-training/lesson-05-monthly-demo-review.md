# Lesson 05 — Monthly Demo와 성장 Review

## 목표
매달 공부를 실제 음악 결과로 압축하고 지난달보다 무엇이 나아졌는지 확인한다.

## 1. 월간 Demo
한 달에 최소 하나의 60~180초 Demo를 완성한다. 모든 곡을 공개할 필요는 없다. 훈련의 목적은 완성 경험과 판단 기록이다.

## 2. Demo 평가

```text
Intent clarity:
Song form:
Groove:
Harmony:
Melody/Hook:
Lyrics/Prosody:
Arrangement:
Vocal:
Mix:
Originality:
Overall:
```

각 항목을 숫자만 쓰지 말고 근거 한 줄을 함께 남긴다.

## 3. 지난달과 비교

```text
Improved:
Still weak:
Repeated mistake:
New technique learned:
Technique actually used:
Theory understood but not usable yet:
```

## 4. 다음 달 집중 영역
모든 것을 동시에 개선하지 않는다. 다음 달 핵심 1~2개를 선택한다.

예:
```text
Primary: Chorus melody/hook
Secondary: Groove variation
```

## 5. 프로그램과 분리해서 평가
곡이 약한 이유와 프로그램이 부족한 이유를 분리한다.

```text
Musical weakness:
My skill gap:
AI generation limitation:
DohaMusic product limitation:
External DAW workaround:
```

## 6. 3개월 Review
3개월마다 Demo 3개 이상을 시간 순으로 듣는다. 최신 곡이라는 이유로 점수를 높이지 않고 Blind에 가깝게 비교한다.

## 완료 기준
- [ ] 월간 Demo를 완성했다.
- [ ] 지난달 결과와 비교했다.
- [ ] 다음 달 집중 영역을 1~2개로 좁혔다.
