# Lesson 05 — 실제 곡을 Song Form으로 분석하기

## 학습 목표

좋아하는 곡을 단순 감상하지 않고 Section, 시간, 대비, Hook, 전환의 관점으로 분석한다.

## 1. 1차 청취 — 멈추지 않고 구조 표시

첫 재생에서는 곡을 멈추지 않는다. '분위기가 바뀌었다'고 느낀 시간만 기록한다.

```text
00:00
00:15
00:42
00:56
01:24
...
```

이 단계에서는 Section 이름을 맞히려고 하지 않는다.

## 2. 2차 청취 — Section 이름 붙이기

각 경계 앞뒤를 다시 듣고 Intro, Verse, Pre-Chorus, Chorus, Post-Chorus, Bridge, Outro 중 가장 적절한 역할을 붙인다.

## 3. 3차 청취 — 변화 요소 기록

각 Section마다 다음을 적는다.

- Drum pattern
- Bass
- Chord movement
- Vocal range
- Melody rhythm
- Instrument density
- Stereo width
- Main hook
- Energy 1–10

## 4. 4차 청취 — 전환 분석

특히 다음 전환을 집중해서 듣는다.

```text
Verse → Pre-Chorus
Pre-Chorus → Chorus
Chorus → Verse 2
Bridge → Final Chorus
```

전환 직전 1~2마디에서 어떤 일이 일어나는지 찾는다. Fill, Silence, Riser, Chord tension, Vocal pickup, Drum stop처럼 다음 Section을 예고하는 장치가 있을 수 있다.

## 5. 분석 템플릿

```text
Track:
Artist:
Date analyzed:
Purpose of analysis:

FORM
00:00–00:00 Intro
00:00–00:00 Verse 1
00:00–00:00 Pre-Chorus
00:00–00:00 Chorus

BEST HOOK:

BEST TRANSITION:

ENERGY CURVE:

VERSE → CHORUS CONTRAST
- melody:
- rhythm:
- harmony:
- arrangement:
- vocal:

WHAT I WANT TO LEARN FROM THIS TRACK:

WHAT I SHOULD NOT COPY:
```

마지막 두 항목은 Reference Analysis에서 특히 중요하다. 레퍼런스는 복제 대상이 아니라 학습 대상이다.

## 6. DohaMusic으로 분석하기

현재 `/projects/[id]`의 Composition Read Workspace에서 자신이 만든 결과를 재생할 때 같은 템플릿을 사용한다. playhead 시간을 기록하고 zoom/seek를 사용해 전환 지점을 반복 청취한다.

외부 상업곡을 DohaMusic에 무단 ingestion하는 것을 기본 학습 절차로 가정하지 않는다. 권리와 사용 범위를 확인할 수 없는 Reference는 외부 플레이어에서 듣고 분석 노트만 작성한다.

## 완료 기준

- 한 곡을 최소 5개 이상의 Section으로 나눌 수 있다.
- 각 경계를 음악적인 이유와 함께 설명할 수 있다.
- 가장 강한 Hook과 가장 효과적인 전환을 구분할 수 있다.
- 레퍼런스에서 '배울 것'과 '복제하면 안 되는 것'을 따로 기록할 수 있다.
