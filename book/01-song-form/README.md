## Part 01에서 반드시 할 것

### 듣기

좋아하는 곡을 최소 3곡 분석한다. 한 곡은 K-pop/Pop, 한 곡은 Ballad 또는 느린 곡, 한 곡은 구조가 다른 장르를 선택한다.

각 곡에서 다음을 기록한다.

- Section boundary와 시간
- First Hook time
- Verse → Chorus 대비
- Best transition
- Energy Curve
- 무엇을 배우고 싶은지
- 무엇을 복제해서는 안 되는지

### 직접 작곡

Demo Song 하나의 Music Intent와 Section Map을 먼저 만든다. 음표를 쓰기 전에 각 Section의 길이, 역할, Energy, 악기 밀도와 보컬 방향을 정한다.

### DohaStudio

현재 `DohaMusic/develop`의 Composition Read Workspace에서 자신이 만든 결과를 재생하고 playhead/seek/zoom을 사용해 실제 Section 경계를 기록한다.

`CURRENT`로 볼 수 있는 것은 읽기 전용 Timeline, Track lane, media duration, playback/playhead/seek/zoom 기반이다. Section 편집, 완전한 Track/Clip editing, MIDI/Piano Roll, Section regeneration은 현재 사용 가능한 기능으로 간주하지 않는다.
