# Lesson 08 — Available Note Scale

## 1. 개념
Available Note Scale은 특정 chord 위에서 사용할 수 있는 melody/improvisation 음을 **chord tone, tension, context-sensitive note** 관점으로 정리하는 방법이다.

목표는 `코드마다 스케일 하나 암기`가 아니다. 실제로는 key, chord function, melody, voice leading에 따라 선택이 달라진다.

## 2. 출발 순서
```text
1. Chord tones 확인
2. Chord function 확인
3. Key/tonal center 확인
4. 가능한 tensions 확인
5. 강하게 충돌하는 음과 resolution 확인
6. 실제 melody phrase로 검증
```

## 3. Diatonic Example
C Major 안의 Dm7에서는 C major의 음들을 사용할 수 있지만 chord tone D-F-A-C와 나머지 E(9), G(11), B(13)의 역할을 구분해서 듣는다.

G7에서는 G-B-D-F가 chord tone이고 A(9), E(13) 등은 tension으로 사용할 수 있다. C는 G7의 3rd B와 minor 9th 충돌을 만들 수 있어 강하게 유지할 때 주의가 필요하지만 passing/suspension/resolution 문맥에서는 사용할 수 있다.

## 4. Dominant와 선택지
Dominant chord는 resolution 방향에 따라 Mixolydian 계열, altered color, diminished/whole-tone 계열 등 여러 선택지가 생길 수 있다. 하나의 정답 scale보다 **어떤 tension을 만들고 어디로 해결할지**가 핵심이다.

## 5. Minor ii–V–i Example
```text
Bm7b5 → E7 → Am
```

각 chord에서 melody candidate를 만들고 다음을 확인한다.
- chord tone landing
- available tension
- altered tension
- semitone resolution
- phrase continuity

## 6. AI Melody Evaluation
AI melody candidate가 chord 위에 있다고 해서 단순히 'scale 안/밖'으로 판정하지 않는다.

```text
Note:
Chord:
Beat strength:
Duration:
Chord tone / tension / non-chord tone:
Resolution:
Musical result:
```

## 핵심
Available Note Scale은 **사용 가능한 음 목록이 아니라 chord와 melody 사이 tension-management framework**로 이해한다.
