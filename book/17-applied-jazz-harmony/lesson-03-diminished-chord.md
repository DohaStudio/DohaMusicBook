# Lesson 03 — Diminished Chord

## 1. 구조
Diminished triad는 root–minor 3rd–diminished 5th로 이루어진다. Diminished 7th chord는 여기에 diminished 7th가 더해져 대칭적인 minor-third 구조를 만든다.

예:
```text
Bdim7 = B D F Ab
```

## 2. 기능
Diminished chord는 독립적인 색채보다 **접근·연결·dominant 기능 확장**에 자주 쓰인다.

대표 용도:
- leading-tone diminished
- passing diminished
- common-tone diminished
- dominant 7(b9)의 rootless 구조와 연결

## 3. Leading-Tone Diminished
C로 해결하려면 Bdim7이 강한 반음 진행을 만든다.

```text
B → C
D → E 또는 C
F → E
Ab → G
```

## 4. Passing Diminished
두 diatonic chord 사이 bass를 반음 또는 순차적으로 연결하는 역할로 사용할 수 있다.

예:
```text
Cmaj7 → C#dim7 → Dm7
```

## 5. 대칭성
Diminished 7th는 minor 3rd 간격으로 쌓이기 때문에 inversion을 바꿔도 같은 pitch-class set을 유지한다. 이 성질은 여러 방향으로 해결 가능한 ambiguity를 만든다.

## 6. 실습
```text
A: Cmaj7 | Dm7 | G7 | Cmaj7
B: Cmaj7 | C#dim7 | Dm7 | G7
C: Cmaj7 | Bdim7 | Cmaj7 | -
```

기록:
- diminished의 목표 chord
- 각 성부의 반음 이동
- bass line 개선 여부
- melody compatibility

## 핵심
Diminished chord는 `특이한 코드`가 아니라 **voice leading을 촘촘하게 만들고 목표 chord를 강조하는 연결 장치**로 이해한다.
