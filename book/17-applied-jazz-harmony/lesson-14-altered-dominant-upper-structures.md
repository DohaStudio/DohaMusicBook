# Lesson 14 — Altered Dominant와 Upper Structure

## 목표
Dominant chord의 tension을 무작정 추가하지 않고 resolution target과 melody context를 기준으로 선택한다.

## 1. Dominant의 핵심
V7의 3rd와 7th가 만드는 tritone은 tonic으로 향하는 강한 voice leading을 만든다. Alteration은 이 기본 기능 위에 tension color를 추가한다.

## 2. Altered Tensions
Dominant에서 자주 다루는 색채에는 b9, #9, #11/b5, b13/#5 등이 있다. 모든 alteration을 동시에 넣을 필요는 없다.

예:
```text
G7(b9) → C
G7(#9) → C minor 계열 문맥
G7(b13) → C / Cm 문맥에 따라 비교
```

## 3. Altered Scale 관점
Altered dominant를 melodic minor의 mode와 연결해 이해할 수 있지만, 먼저 chord tones와 실제 resolution을 듣고 scale 이름은 그 다음에 붙인다.

## 4. Upper Structure Triad
기본 dominant shell 위에 다른 triad shape를 올려 tension cluster를 조직할 수 있다. 목적은 복잡한 symbol이 아니라 연주 가능한 voicing과 명확한 color를 만드는 것이다.

## 5. Melody 충돌 확인
Chord voicing의 altered tension과 melody가 semitone collision을 만들더라도 항상 잘못은 아니다. accent, register, duration, resolution을 함께 판단한다.

## 실습
G7 → Cmaj7 또는 G7 → Cm을 기준으로 plain G7과 altered version 최소 4개를 만들고 resolution character를 비교한다.

```text
Alteration:
Guide tones:
Upper notes:
Melody compatibility:
Resolution target:
Color:
Keep/reject:
```
