# Lesson 01 — Functional Harmony Review & Chord Substitution

## 1. 기능화성 다시 보기
화음을 이름보다 기능으로 묶어 듣는다.

```text
Tonic (T)        = 안정 / 귀환
Subdominant (SD) = 이동 / 전개 / Dominant 준비
Dominant (D)     = 긴장 / Tonic으로의 추진
```

C Major에서 대표 예시는 다음과 같다.

```text
T  : Cmaj7, Am7, Em7
SD : Dm7, Fmaj7
D  : G7, Bm7b5(맥락에 따라 dominant family로 연결)
```

실제 곡에서는 한 chord가 항상 하나의 기능만 갖는 것이 아니라 주변 진행과 melody/bass에 따라 역할이 달라질 수 있다.

## 2. 대리화음의 핵심
대리화음은 `비슷한 구성음`, `비슷한 guide tone`, `비슷한 기능`, `유사한 bass destination`을 이용해 원래 chord를 다른 색채로 바꾸는 방법이다.

### 공통음
예를 들어 Cmaj7과 Am7은 C와 E를 공유한다. 둘 다 tonic 계열로 사용할 수 있지만 bass가 C인지 A인지에 따라 안정감의 중심이 달라진다.

### Guide Tone
3rd와 7th는 7th chord의 기능을 강하게 드러낸다. 특히 dominant 7th에서는 3rd와 b7 사이 tritone이 해결 방향을 만든다.

## 3. 기능을 유지한 대리
```text
Cmaj7 → Am7
Fmaj7 → Dm7
G7 → Db7  (tritone substitution, 자세한 내용은 Part 03/후속 Lesson 참고)
```

대리 후에도 `어디에서 왔고 어디로 가는지`가 유지되는지 들어야 한다.

## 4. Voice Leading
좋은 대리는 chord symbol만 화려한 것이 아니라 각 성부가 작은 거리로 자연스럽게 이동하는 경우가 많다.

```text
현재 chord의 3rd / 7th
→ 다음 chord의 가까운 chord tone 또는 tension
```

## 5. 실습
기본 진행 `Cmaj7 | Am7 | Dm7 | G7`을 만든 뒤 다음을 비교한다.

```text
A. 원형
B. tonic substitute 변경
C. subdominant family 변경
D. dominant substitute 변경
```


## 핵심
대리화음은 코드 이름을 바꾸는 기술이 아니라 **기능을 유지하거나 의도적으로 비틀면서 voice leading과 색채를 조절하는 방법**이다.
