# Lesson 13 — Guide Tones와 Jazz Voicing

## 목표
Jazz chord를 모든 음을 똑같이 쌓는 block chord로만 생각하지 않고 기능을 결정하는 핵심 음과 voice leading으로 듣는다.

## 1. Guide Tone
7th chord에서 3rd와 7th는 chord quality와 function을 강하게 드러내는 핵심 음이다.

C major ii–V–I:
```text
Dm7  : F(3rd), C(7th)
G7   : B(3rd), F(7th)
Cmaj7: E(3rd), B(7th)
```

Guide tone만 연주해도 voice leading 방향을 들을 수 있다.

## 2. Shell Voicing
Root + 3rd + 7th처럼 최소 정보만 남긴 voicing을 만든다. Bass player가 root를 담당한다면 piano/guitar comping에서는 root를 생략할 수도 있다.

## 3. Close / Open Voicing
Chord tones를 좁은 범위에 배치한 close voicing과 octave displacement로 넓힌 open voicing을 비교한다. 같은 chord symbol도 register 때문에 밀도와 clarity가 크게 달라진다.

## 4. Drop Voicing
Close-position chord에서 특정 voice를 octave 아래로 내려 더 열린 구조를 만든다. Drop 2를 출발점으로 실제 소리를 비교한다. 공식 암기보다 각 voice가 어디로 이동했는지 추적한다.

## 5. Voice Leading
좋은 voicing은 매 chord마다 새로운 모양을 잡는 것이 아니라 common tone을 유지하고 다른 voice가 가까운 목표음으로 움직이도록 설계할 수 있다.

## 실습
```text
Progression: Dm7 G7 Cmaj7
A: root-position block
B: guide tones only
C: shell voicing
D: close voicing
E: open/drop-style voicing
```

각 버전의 smoothness, density, bass conflict, melody space를 기록한다.
