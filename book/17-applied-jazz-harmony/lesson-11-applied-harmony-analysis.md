# Lesson 11 — Applied Harmony Analysis

## 목표
복잡한 코드 이름을 한 번에 읽으려 하지 않고 실제 곡의 화성을 기능·베이스·보이스리딩·텐션으로 단계적으로 분석한다.

## 분석 순서
```text
1. Tonal center / Key
2. Bass line
3. Diatonic or non-diatonic
4. Function
5. Target chord
6. Guide-tone movement
7. Tension / altered note
8. Cadence / resolution
9. Melody compatibility
10. Section role
```

## 1. Bass부터 듣기
Bass가 root인지 inversion/slash bass인지 확인한다. 같은 upper chord라도 bass가 바뀌면 기능과 연결감이 달라질 수 있다.

## 2. Non-Diatonic Chord 분류
조성 밖 chord를 발견하면 즉시 '전조'라고 판단하지 않는다.

가능성:
- Secondary dominant
- Modal interchange
- Passing diminished
- Tritone substitute
- Chromatic approach
- Brief tonicization
- Actual modulation

## 3. Target 찾기
낯선 chord 자체보다 `어디로 해결되는가`를 본다. 특히 dominant 계열에서는 다음 chord가 분석의 핵심이다.

## 4. Guide Tone 그리기
각 7th chord의 3rd와 7th를 별도 voice로 적어 다음 chord까지 선으로 연결한다. 작은 반음 이동이 진행의 설득력을 만드는 경우가 많다.

## 5. Melody 동시 분석
Harmony만 따로 분석하지 않는다.

## 완료 기준
최소 한 곡의 8~16마디를 Roman Numeral과 기능, bass, tension, melody까지 함께 분석한다.
