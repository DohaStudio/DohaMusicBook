# Lesson 02 — AI 산출물과 서비스 약관

## 학습 목표
- AI 생성 결과의 인간 창작 기여를 기록한다.
- 외부 서비스 약관을 고정 사실이 아니라 변경 가능한 조건으로 다룬다.
- 상업 이용 가능 여부와 저작권 인정 여부를 분리한다.

## 1. AI 산출물은 창작 과정을 기록한다
AI가 만든 결과라고 해서 모두 같은 수준의 인간 개입을 갖는 것은 아니다.

예:
```text
Prompt only
Prompt + lyric rewrite
Prompt + section rearrangement
Prompt + melody/chord manual edit
Prompt + arrangement + mix/master
```

법적 결론을 자동으로 내리지 않더라도 어떤 부분을 사람이 만들고 수정했는지 provenance를 남긴다.

## 2. Human Contribution Log
```text
Project:
Source generation:
Human-written lyrics:
Human melody edits:
Human chord edits:
Human arrangement edits:
Human recording:
Human mix/master:
Final selection reason:
```

## 3. 서비스 약관
Suno, Udio 등 외부 서비스는 플랜·Ownership·상업 이용·데이터 이용 조건이 바뀔 수 있다. 책에는 '현재 확인한 조건'으로 기록한다.

```text
Service:
Plan:
Checked date:
Commercial use:
Ownership wording:
Input rights requirement:
Output restrictions:
Training/data use terms:
Official source:
```

## 4. 확인 습관
발매 시점에 다시 확인한다. 과거에 허용되었던 플랜 조건을 현재도 동일하다고 가정하지 않는다.

## 5. DohaStudio 연결
외부 AI Provider를 사용할 경우 Job/Artifact에 provider, terms/version 또는 확인 근거를 연결할 수 있어야 한다. 최소한 어떤 서비스·모델·설정에서 결과가 나왔는지 lineage를 보존한다.

## 완료 체크
- [ ] AI 결과의 인간 기여를 기록했다.
- [ ] 상업 이용과 저작권 문제를 구분한다.
- [ ] 사용하는 AI 서비스 약관을 공식 출처에서 다시 확인하는 절차를 안다.
