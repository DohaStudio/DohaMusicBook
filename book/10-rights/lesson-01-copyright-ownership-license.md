# Lesson 01 — Copyright, Ownership, License를 구분한다

## 학습 목표
- 저작권, 소유권, 사용 허가를 분리해서 질문한다.
- 저작인격권·저작재산권·저작인접권의 큰 틀을 이해한다.
- AI 음악에서도 '내 파일'과 '내 저작권'을 같은 말로 쓰지 않는다.

## 1. 세 질문을 분리한다

```text
Copyright: 법적으로 저작권이 인정되는가?
Ownership: 계약/약관상 누가 결과물 또는 파일을 소유하는가?
License: 누가 어떤 범위에서 사용할 수 있는가?
```

세 질문은 서로 연결되지만 동일하지 않다.

## 2. 저작권의 큰 분류

### 저작인격권
창작자의 인격과 결부된 권리 영역이다.

### 저작재산권
복제·배포·공중송신 등 경제적 이용과 관련된 권리 영역이다.

### 저작인접권
실연자·음반제작자 등 음악을 실제로 공연·제작·전달하는 주체와 관련된 권리다.

실제 적용은 국가와 계약에 따라 달라질 수 있으므로 이 책은 법률 자문을 대신하지 않는다.

## 3. 음악 프로젝트에서 자주 생기는 오해

```text
파일을 내가 가지고 있다 = 모든 권리를 가진다      X
무료로 다운로드했다 = 상업 이용 가능               X
Royalty-free = 저작권이 없다                         X
구매했다 = 재배포/학습까지 가능                     X
AI 서비스가 ownership을 준다 = 저작권 등록 가능     X
```

각 이용 목적별 허용 범위를 따로 확인한다.

## 4. 직접 실습
사용 중인 음악 자산 하나를 고르고 다음을 기록한다.

```text
Asset:
Creator/rightsholder:
Copyright status known?:
Ownership:
License source:
Commercial release allowed?:
Redistribution allowed?:
AI training allowed?:
Attribution required?:
Checked date:
Evidence link/file:
```

## 5. DohaStudio 연결
DohaStudio의 RightsMetadata는 한 개의 `allowed=true` 값으로 모든 권리를 표현하면 안 된다. 작품 사용, 재배포, 학습, 모델 배포 등 scope를 분리해 기록해야 한다.

## 완료 체크
- [ ] Copyright/Ownership/License를 구분한다.
- [ ] 저작권의 큰 분류를 설명한다.
- [ ] 사용 중인 자산 하나의 권리 범위를 직접 조사했다.
