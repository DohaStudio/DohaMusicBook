# Lesson 03 — Release Package와 Delivery

## 목표
Master 파일 하나만 있으면 발매 준비가 끝난다는 생각에서 벗어난다.

## Release Package
```text
Final master WAV
Instrumental (if needed)
Clean/alternate version (if needed)
Artwork
Track title
Artist name
Contributors / credits
Lyrics
Language
Genre metadata
Release date plan
Rights evidence
Identifiers assigned by distributor/industry workflow
```

실제 포맷/Artwork/metadata 요구사항은 선택한 Distributor/DSP의 최신 공식 가이드를 확인한다.

## Export QA
- 파일 시작/끝
- clipping/unwanted silence
- correct master version
- metadata spelling
- artwork ownership
- explicit/clean status
- credits

## Version Lock
```text
mix-v5.wav
master-v1.wav
master-v2-approved.wav
release-master.wav
```

`release-master.wav`가 어느 Mix/Master에서 왔는지 기록한다.

## DohaStudio 연결
향후 Release Package는 Final Artifact와 Rights/Metadata/Version lineage를 묶는 export workflow로 확장할 수 있다. 실제 Distributor 업로드 자동화는 별도 제품 결정이다.
