# Lesson 01 — 발매 전 Rights와 Credits

Part 10의 권리 공부를 실제 Release Gate로 적용한다.

## 확인 항목
```text
Composition authorship
Lyrics authorship
Master owner
Performers
Producer/arranger credits
Samples/loops
SoundFont/virtual instrument license
AI service terms
Voice consent
Artwork rights
Collaborator splits/agreements
```

권리 정보가 불명확하면 '나중에 정리'하지 않고 release blocker로 기록한다.

## Release Rights Record
```text
Track:
Composition owner(s):
Master owner(s):
Credits confirmed:
Sample evidence:
AI contribution/evidence:
Voice consent:
Artwork evidence:
Open issue:
Release ready: yes/no
```

법적 판단이 필요한 분쟁/불확실성은 전문 자문 대상이며 이 체크리스트가 법률 의견을 대신하지 않는다.
