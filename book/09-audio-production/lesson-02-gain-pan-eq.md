# Lesson 02 — Gain, Pan, EQ: Mix의 기본 균형

## 학습 목표
- Gain staging과 Fader balance를 구분한다.
- Pan으로 공간을 배치한다.
- EQ를 문제 해결과 색채 조절에 사용한다.

## 1. Gain과 Headroom
Mix 시작 전에 Track 간 레벨을 정리하고 Master에 여유를 남긴다. 크게 들리는 소리를 무조건 좋은 소리로 착각하지 않도록 A/B 시 레벨 차이를 주의한다.

## 2. Balance
처음에는 Plugin 없이 Fader만으로 곡이 얼마나 정리되는지 확인한다. Vocal, Kick, Bass, Snare, 주요 Harmony/Lead의 상대적 우선순위를 듣는다.

## 3. Pan
좌우 위치를 이용해 요소를 분리한다. 핵심 Low-end와 Lead를 Center에 두는 관습은 유용한 출발점이지만 절대 규칙은 아니다.

## 4. EQ
EQ를 사용할 때 먼저 질문한다.

```text
문제가 실제로 들리는가?
어느 Track과 충돌하는가?
Cut이 필요한가, Boost가 필요한가?
Arrangement 문제를 EQ로 억지로 고치고 있지 않은가?
```

주파수 숫자를 암기하기보다 sweep와 bypass를 통해 실제 변화량을 듣는다.

## 5. Masking
두 악기가 비슷한 대역과 음역을 차지하면 서로 가릴 수 있다. 해결 순서는 보통 Arrangement/Register 확인 → Level/Pan → 필요한 EQ 순으로 생각한다.

## 6. 실습
같은 Mix를 세 단계로 저장한다.

```text
A: raw levels
B: fader + pan only
C: B + corrective EQ
```

각 단계에서 Vocal clarity, Low-end, 악기 분리도를 기록한다.

## 7. DohaStudio 연결
향후 Mixer가 구현되면 Track gain/pan과 processing chain은 Composition의 편집 상태와 연결되어야 한다. 현재 완성형 Mixer UI가 있다고 가정하지 않는다.

- [ ] Plugin 없이 기본 Balance를 만들었다.

- [ ] EQ 전후를 level-matched에 가깝게 비교했다.
