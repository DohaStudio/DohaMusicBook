# Lesson 05 — Mixing, Mastering, Reference Track

## 학습 목표
- Mixing과 Mastering의 책임을 구분한다.
- Loudness와 Peak를 별개 관점으로 본다.
- Reference Track을 복제가 아니라 기준점으로 사용한다.

## 1. Mixing
개별 Track을 하나의 음악으로 균형 있게 결합하는 과정이다.

주요 질문:
- Lead가 명확한가?
- Low-end가 통제되는가?
- Section dynamics가 살아 있는가?
- 악기들이 공간을 공유하면서도 구분되는가?

## 2. Mastering
완성된 Mix를 최종 배포 환경에 맞게 준비한다. Tonal balance, loudness, peak control, translation 등을 본다. Mix에서 해결해야 할 큰 문제를 Master에서 억지로 수정하지 않는다.

## 3. Loudness와 True Peak
Loudness는 청감상 평균적인 크기와 관련되고 Peak는 순간적인 최대 레벨과 관련된다. 특정 수치를 모든 음악에 절대 공식처럼 적용하지 않고 배포 플랫폼과 장르 목적을 확인한다.

## 4. Limiter
최종 Peak를 제어하고 필요한 경우 Loudness를 올리는 데 사용한다. 과도하면 transient와 dynamics가 무너질 수 있다.

## 5. Reference Track
유사한 장르·목적의 상업 음원을 비교 기준으로 사용한다.

```text
Low-end:
Vocal level:
Brightness:
Width:
Punch:
Section contrast:
Loudness impression:
```

가능하면 비교 시 체감 음량을 맞춘다. 더 큰 소리가 더 좋은 소리처럼 느껴지는 편향을 줄이기 위해서다.

## 6. Translation
Headphone 하나에서만 좋은 Mix가 아니라 여러 재생 환경에서 핵심이 유지되는지 확인한다.

- Headphones
- Earbuds
- Phone speaker
- Small speaker
- Mono check

## 7. 실습
원본 Mix와 Master 버전을 비교한다.

```text
What improved:
What became worse:
Transient change:
Low-end change:
Vocal position:
Fatigue after repeated listening:
Keep / revise:
```

## 8. DohaStudio 연결
최종 Export는 어떤 Composition/Snapshot에서 어떤 processing을 거쳐 만들어졌는지 lineage가 남아야 한다. Mastered file 하나만 보존하고 작업 근거를 잃지 않는다.

## 완료 체크
- [ ] Mixing과 Mastering을 구분한다.
- [ ] Loudness와 Peak 차이를 설명한다.
- [ ] Reference를 level-aware하게 비교했다.
- [ ] 여러 재생 환경에서 Translation을 확인했다.
