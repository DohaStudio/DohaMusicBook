## 핵심 원칙

- 가장 비싼 PC보다 작업이 끊기지 않는 안정적인 구성이 중요하다.
- CPU/RAM/Storage/GPU의 역할을 구분한다.
- Sample library와 Project 원본을 뒤섞지 않는다.
- 낮은 Buffer가 항상 좋은 것은 아니다.
- Recording 단계와 Mixing 단계의 Buffer 요구가 다를 수 있다.
- Plugin 설치 위치, License, Version을 기록한다.
- Project 파일, Audio 원본, Export, AI Artifact를 구분한다.
- Git에는 대용량 Audio/Model/Sample을 넣지 않는다.

## 완료 기준

```text
[ ] 내 PC에서 음악 작업 병목이 CPU/RAM/Storage/GPU 중 무엇인지 설명할 수 있다.
[ ] Audio Interface와 Buffer 설정 의미를 안다.
[ ] Sample/Plugin/Project 폴더를 분리했다.
[ ] DAW/Plugin 설치 및 라이선스 기록 방법이 있다.
[ ] 작업 파일의 Backup/Version 정책을 정했다.
[ ] DohaStudio Artifact와 외부 DAW Project의 관계를 설명할 수 있다.
```
