# Lesson 04 — Monitoring과 Recording Setup

## 목표
좋은 장비보다 일관된 청취 환경과 깨끗한 녹음 습관을 먼저 만든다.

## 1. Headphone과 Speaker
Headphone은 세부 Noise, edit, stereo detail 확인에 유리하고 Speaker는 공간과 실제 재생 환경을 판단하는 데 도움이 된다. 하나만 절대 기준으로 삼지 않는다.

## 2. Monitoring Level
너무 큰 음량은 판단을 흐리고 피로를 높인다. 대부분의 작업은 일정한 중간 음량에서 하고 작은 음량과 큰 음량을 보조 확인용으로 사용한다.

## 3. Recording Chain

```text
Source
→ Microphone / Instrument
→ Preamp / Audio Interface
→ Driver / DAW input
→ Recording Take
```

각 단계에서 clipping과 noise가 생기는지 확인한다.

## 4. Input Gain
녹음 단계에서 신호를 과도하게 키워 clipping을 만들지 않는다. Mix 단계에서 올릴 수 있는 레벨과 녹음 단계에서 이미 깨진 Audio는 다르다.

## 5. Room과 Noise
완벽한 Studio가 아니어도 반복 가능한 위치와 환경을 만든다.

- PC fan/air conditioner noise
- reflective wall
- microphone distance
- pop/noise control
- cable/contact noise

## 6. Take 관리
좋은 Take를 만들기 위해 원본을 계속 덮어쓰지 않는다.

```text
lead_vocal_take_01.wav
lead_vocal_take_02.wav
lead_vocal_take_03.wav
```

Comping 전에는 원본 Take를 유지한다.

## 7. Vocal/Voice Rights
Recording Take와 Voice Enrollment Sample은 목적이 다르다. 실제 작품 녹음 파일을 Training Dataset으로 자동 재사용하지 않는다.

## 완료 기준
- [ ] Input clipping과 Mix clipping을 구분한다.
- [ ] 일관된 Monitoring 환경을 만든다.
- [ ] Take를 덮어쓰지 않고 관리한다.
- [ ] Recording Take와 Voice Enrollment 목적을 구분한다.
