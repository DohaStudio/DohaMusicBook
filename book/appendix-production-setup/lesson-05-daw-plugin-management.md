# Lesson 05 — DAW, Plugin, Virtual Instrument 관리

## 목표
DAW와 Plugin을 설치하는 것보다 버전, 위치, 라이선스, 프로젝트 재현성을 관리한다.

## 1. DAW 선택
DAW마다 Workflow와 기본 도구가 다르다. 특정 DAW가 절대적으로 우월하다고 보지 않고 다음을 기준으로 선택한다.

- MIDI editing
- Audio editing
- Mixer/Automation
- Plugin support
- Stability
- Export workflow
- Documentation/community

DohaMusic은 별도 AI-native DAW 제품이며 외부 DAW 사용 경험을 그대로 복제하는 것이 아니라 실제 작곡 필요를 학습 자료로 사용한다.

## 2. Plugin 종류

```text
Instrument plugin
Effect plugin
Analyzer
Utility
```

VST/VST3/AU 등 format과 host 지원 범위를 구분한다.

## 3. Virtual Instrument
Synth와 Sample-based Instrument를 구분한다. Sample library는 Plugin 실행 파일과 별도 용량/라이선스를 가질 수 있다.

## 4. Plugin Inventory

```text
Name:

```

## 5. Version 변경
Plugin update가 항상 기존 Project와 완전히 호환되는 것은 아니다. 중요한 Project는 사용 버전과 preset 정보를 기록한다.

## 6. Preset 관리
Factory preset, purchased preset, user preset을 구분한다. 좋은 preset을 그대로 쓰는 것보다 어떤 parameter가 소리를 바꾸는지 분석한다.

## 7. Plugin 수집을 공부로 착각하지 않는다
새 Plugin 구매보다 현재 도구로 Song Form, Melody, Harmony, Arrangement, Mix를 끝까지 수행하는 능력이 먼저다.
