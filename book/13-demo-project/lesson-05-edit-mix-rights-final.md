# Lesson 05 — Human Edit, Mix/Master, Rights, Final Review

## 목표
선택한 AI 후보를 사람이 수정해 완성도를 높이고, 최종 음원 이전에 권리와 품질을 함께 점검한다.

## 1. Editing Decision
문제마다 수정 방법을 선택한다.

```text
Problem:
Musical cause:
Action: regenerate / MIDI edit / audio edit / vocal edit / arrangement edit
Reason:
A/B result:
Keep or revert:
```

현재 DohaMusic에서 직접 할 수 없는 MIDI/Clip/Mixer 수정은 외부 DAW에서 수행하고 `TARGET` product gap과 구분한다.

## 2. Editing Checklist

```text
Song form:
Melody:
Chord:
Rhythm/timing:
Instrument replacement:
Arrangement density:
Lyrics/prosody:
Vocal timing/pitch:
Audio cleanup:
```

## 3. Mix Review

```text
Gain balance:
Low-end:
Vocal position:
EQ conflicts:
Compression:
Reverb/delay:
Stereo:
Automation:
Section dynamics:
```

원본 후보와 후처리 버전을 A/B한다.

## 4. Master Review

```text
Tonal balance:
Loudness impression:
Peak/clipping:
Transient preservation:
Reference comparison:
Translation devices checked:
```

## 5. Rights Review

```text
AI service / plan / checked date:
Samples:
Virtual instruments:
SoundFont:
Voice consent:
External models:
Reference audio reused?:
Human contribution:
Similarity concerns:
```

`상업 이용 가능`이라는 한 줄로 모든 권리를 합치지 않는다.

## 6. Final Listening
가능하면 작업 직후가 아니라 시간을 두고 다시 듣는다.

- 첫 30초가 목적에 맞는가?
- Chorus hook을 기억할 수 있는가?
- Verse→Pre→Chorus 대비가 들리는가?
- 가사가 자연스러운가?
- 불필요한 Layer가 있는가?
- Vocal이 무리하게 들리는 구간이 있는가?
- Reference에 지나치게 가까운 요소가 있는가?
- 전체 곡이 처음 Intent와 일치하는가?

## 7. Final Decision

```text
Status: final / revise / abandon
Best quality:
Biggest weakness:
What I learned:
What I would do differently next song:
```

## 완료 조건
- [ ] 선택 후보를 최소 한 번 사람이 수정했다.
- [ ] 원본과 수정본을 A/B했다.
- [ ] Mix/Master를 분리해 검토했다.
- [ ] Rights checklist를 완료했다.
- [ ] 최종 판단 근거를 기록했다.
