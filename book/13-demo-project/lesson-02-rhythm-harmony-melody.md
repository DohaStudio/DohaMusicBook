# Lesson 02 — Core Composition: Rhythm, Harmony, Melody

## 목표
곡의 핵심 음악 재료를 만든다. AI 생성 전에 사람이 최소한의 Rhythm/Harmony/Melody 설계를 가지고 있어야 후보를 평가할 기준이 생긴다.

## 1. Rhythm Plan

```text
BPM:
Meter:
Feel:
Kick concept:
Snare/Clap concept:
Hi-hat subdivision:
Bass rhythm:
Main syncopation:
Verse groove:
Chorus groove:
```

Verse와 Chorus의 차이를 악기 수보다 리듬의 움직임으로도 만든다.

## 2. Harmony Plan

```text
Key:
Verse progression:
Pre progression:
Chorus progression:
Bridge progression:
Harmonic rhythm:
Bass movement:
Reharmonization idea:
```

Pre-Chorus에서 긴장을 만들고 Chorus가 어떻게 해결되거나 열린 상태를 유지할지 적는다.

## 3. Core Motif
2~5개의 핵심 Note/리듬 아이디어를 만든다.

```text
Motif pitches:
Motif rhythm:
Contour:
Strong beat notes:
Rest position:
```

## 4. Section Melody

```text
Verse range:
Verse contour:
Pre range:
Pre tension note:
Chorus range:
Chorus hook:
Highest note:
Resolution note:
```

Chorus가 단순히 음이 높기만 한지, 실제로 기억되는 Motif가 있는지도 확인한다.

## 5. A/B 스케치
최소 두 버전을 만든다.

```text
Version A:
- stronger rhythmic hook
- simpler harmony

Version B:
- smoother rhythm
- more harmonic tension
```

어떤 버전이 Intent에 더 맞는지 이유를 쓴다.

## 6. DohaStudio 연결
현재 MIDI/Piano Roll 직접 편집이 없다면 외부 DAW 또는 노트 문서에서 이 스케치를 만들고, DohaMusic Generation의 후보가 이 계획과 얼마나 일치하는지 비교한다.

## 완료 조건
- [ ] Rhythm plan을 작성했다.
- [ ] Verse/Pre/Chorus progression을 만들었다.
- [ ] Core motif를 만들었다.
- [ ] Chorus hook 두 버전을 비교했다.
