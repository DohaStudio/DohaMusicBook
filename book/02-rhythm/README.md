## 핵심 개념

Rhythm은 단순한 드럼 패턴이 아니라 음이 언제 시작되고 얼마나 유지되며 어디에 강세가 놓이는지에 관한 시간 구조다.

```text
Rhythm = pulse
       + meter/grouping
       + subdivision
       + accent
       + note placement
       + note length
       + velocity/dynamics
       + repetition/variation
       + interaction between parts
```

Part 02에서는 4/4 중심의 실용 Groove에서 시작해 Straight/Swing/Shuffle, Syncopation, Pickup, Drum Beatmaking, Polyrhythm을 익힌 뒤 Simple/Compound Meter, 3/4와 6/8, Tuplet, Hemiola, Odd/Additive Meter의 기초까지 확장한다.

## DohaStudio와 연결

### CURRENT
현재 DohaMusic은 WAV playback과 Timeline 확인이 가능하므로 생성된 곡의 실제 시간 흐름을 들으며 BPM과 Section별 리듬 밀도를 분석하는 용도로 사용할 수 있다. 이를 완전한 MIDI 리듬 편집기로 오해하지 않는다.

### TARGET
향후 MIDI Track/Piano Roll이 구현되면 `Note.start`, `duration`, `velocity`, `Tempo`, `Meter`, `Quantization`, `Swing`, `Humanization`뿐 아니라 beat grouping/subdivision 같은 분석 정보도 음악적 검토 대상이 될 수 있다. 실제 구현 계약은 최신 설계를 우선한다.

## 이 Part를 끝냈다면

- Tempo와 Groove를 구분해서 설명할 수 있다.
- Straight와 Swing/Shuffle 차이를 들을 수 있다.
- Syncopation과 Pickup을 찾아낼 수 있다.
- Kick/Bass/Hi-hat/Vocal의 상호작용을 따로 들을 수 있다.
- 직접 Drum Pattern을 만들고 발전시킬 수 있다.
- Subdivision과 Polyrhythm을 귀로 분리해서 들을 수 있다.
- Simple/Compound Meter와 3/4/6/8의 grouping 차이를 설명한다.
- Tuplet과 Swing을 동일시하지 않는다.
- Hemiola/Odd Meter의 기본 accent grouping을 만들 수 있다.
- 생성 결과를 Rhythm 관점으로 평가할 수 있다.
