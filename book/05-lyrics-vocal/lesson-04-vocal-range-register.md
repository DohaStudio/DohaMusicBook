# Lesson 04 — Vocal Range와 Register: 실제로 부를 수 있는 멜로디를 설계한다

## 학습 목표
- 최저음/최고음과 Tessitura를 구분한다.
- Section별 Vocal Range를 Energy Curve와 연결한다.
- Register와 발성 강도가 같은 Note의 인상을 바꾸는 이유를 이해한다.

## 1. Range와 Tessitura
Range는 곡에서 사용되는 최저음과 최고음의 범위다. Tessitura는 보컬이 가장 오래 머무는 실제 중심 음역이다. 최고음 하나만 보고 곡의 난이도를 판단하면 안 된다.

```text
Lowest note:
Highest note:
Main tessitura:
Longest sustained note:
Hardest phrase:
```

## 2. Section별 음역 설계
예시:

```text
Verse: comfortable low-mid
Pre: gradual rise
Chorus: higher tessitura / wider range
Bridge: contrast or reset
Final Chorus: optional climax
```

항상 Chorus가 가장 높아야 하는 것은 아니지만, 음역 변화는 Section Contrast를 만드는 강력한 수단이다.

## 3. Register
같은 음도 chest-dominant, mix, head-dominant, breathy 등의 발성 방식에 따라 에너지와 질감이 달라진다. 특정 용어를 절대적인 생리학적 구분으로 사용하기보다 실제 듣기와 보컬 디렉팅 관점에서 기록한다.

## 4. Expression
- breathy / airy
- clean
- intimate
- strong
- belted
- restrained
- spoken-like

이런 표현은 음높이 정보와 별도로 Vocal Style을 설명한다.

## 5. 직접 실습
Verse와 Chorus의 보컬 설계를 작성한다.

```text
Verse range:
Verse expression:
Pre range:
Pre expression:
Chorus range:
Chorus expression:
Climax note:
Breath risks:
```

## 6. DohaVocal 연결
DohaVocal은 보컬 Provider 경계로 이해한다. Voice Enrollment, Singing Voice Generation, Voice Conversion, Pitch/Timing Correction 같은 개념은 서로 다른 workflow다. 현재 구현 상태를 최신 원본 저장소에서 확인하고 Foundation/Target을 구분한다.
