# Lesson 02 — Syllable과 Prosody: 말의 리듬을 멜로디에 맞춘다

## 학습 목표
- 가사의 음절 수를 세고 Melody Rhythm과 맞춘다.
- 말의 강세와 음악의 강세가 충돌하는 지점을 찾는다.
- 호흡과 문장 의미가 자연스럽게 이어지는 Phrase를 만든다.

## 1. 음절 수
한국어 가사는 음절 단위가 비교적 분명하다.

```text
너를 다시 만나면
너 / 를 / 다 / 시 / 만 / 나 / 면
```

같은 문장이라도 어떤 음절을 길게 늘이고 어떤 음절을 짧게 지나가는지에 따라 인상이 달라진다.

## 2. Prosody
Prosody는 말의 자연스러운 억양, 강세, 호흡이 멜로디와 잘 맞는지를 본다.

체크할 것:
- 핵심 단어가 강박 또는 긴 음가에 놓이는가?
- 조사/어미가 불필요하게 강조되는가?
- 말의 자연스러운 억양과 Melody Contour가 충돌하는가?
- Breath point가 문장 의미를 끊는가?

## 3. 같은 뜻을 다른 리듬으로
한 문장을 두 가지 리듬으로 만들어 실제로 불러본다. 의미가 잘 들리고 발음이 편한 버전을 고른다.

## 4. 직접 실습
Chorus Hook 후보 하나를 만든다.

```text
Hook text:
Syllable count:
Strong syllables:
Long notes:
Breath point:
Awkward word:
Revision:
```

## 5. DohaStudio 연결
향후 Lyrics와 Melody를 함께 다루려면 단순 문자열뿐 아니라 line/phrase/syllable alignment 정보가 필요할 수 있다. 하지만 현재 구현된 canonical schema라고 가정하지 않는다.

- [ ] 어색한 Prosody 한 곳을 수정했다.
- [ ] Breath point를 실제로 불러 확인했다.
