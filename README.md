# DohaMusicBook

DohaStudio의 음악 이론, 작곡, AI 음악 생성, MIDI/DAW, 오디오 프로덕션, 보컬, 권리·출처 관리와 실제 시스템 설계를 연결하는 학습·설계 문서입니다.

## Goal

기존 음악 서적을 복제하거나 단순 요약하는 저장소가 아닙니다. 음악 이론과 제작 원리를 독립적으로 학습하고, 각 개념을 DohaStudio의 실제 음악 제작 시스템에 연결합니다.

`Music Intent → Song Form → Rhythm/Harmony/Melody/Lyrics → Arrangement → AI Generation → Human Review → MIDI/Audio/Vocal Editing → Mix/Master → Rights/Similarity Review → Final Artifact`

## Structure

- `book/` — 책 본문과 전체 커리큘럼
- `labs/` — 음악 개념을 DohaStudio 기능·데이터·실험으로 연결
- `references/` — 참고 도서·논문·공식 문서와 출처 기록
- `glossary/` — 음악/AI/프로덕션 용어집
- `examples/` — 데모 곡 기반 end-to-end 예제
- `diagrams/` — 아키텍처와 제작 흐름 도식

## Writing principles

1. 참고 도서의 문장·표·예제를 그대로 옮기지 않는다.
2. 음악 개념은 여러 자료를 확인하고 DohaStudio 관점에서 새롭게 설명한다.
3. 출처가 필요한 주장과 참고 아이디어는 `references/`에 기록한다.
4. 서비스 기능·약관·가격처럼 변경 가능한 정보는 확인 날짜와 공식 출처를 기록한다.
5. 음악 이론과 현재 DohaStudio 구현 상태를 혼동하지 않는다.
6. `book/`은 안정적인 지식을, `labs/`는 변화 가능한 구현·실험을 중심으로 관리한다.
