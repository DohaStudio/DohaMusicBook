# References

## Purpose

DohaMusicBook 집필에 사용한 참고 자료와 적용 범위를 기록한다. 이 디렉터리는 원문 보관소가 아니다.

## Rules

- 책의 문장, 표, 그림, 예제를 장문으로 복제하지 않는다.
- 참고한 개념은 독립적으로 재서술한다.
- 직접 인용이 필요한 경우 최소 범위로 사용하고 정확한 출처를 남긴다.
- 웹 서비스의 기능, 가격, 라이선스, 약관은 공식 자료와 확인 날짜를 기록한다.
- 저작권/AI 권리처럼 변경 가능하고 법적 판단이 필요한 내용은 최신 공식·1차 자료를 우선한다.
