# Demo Song

이 예제는 책 전체를 관통하는 하나의 end-to-end 작곡 프로젝트를 위한 자리다.

## Planned workflow

1. Music Intent
2. Reference Analysis
3. Song Form
4. Rhythm / Groove
5. Chord Progression
6. Motif / Melody
7. Lyrics / Prosody
8. Arrangement
9. AI Candidates
10. Human Review
11. MIDI Editing
12. Vocal
13. Audio Rendering
14. Mixing
15. Mastering
16. Similarity / Rights Review
17. Final Artifact

실제 곡·레퍼런스·에셋은 라이선스와 공개 가능 범위를 확인한 뒤 추가한다.
