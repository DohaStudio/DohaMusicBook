# Harmony Ear Training MIDI Lab

이 폴더의 MIDI는 DohaMusicBook 학습용으로 직접 생성한 예제다. 먼저 이름을 보지 않고 듣고, 그 다음 Piano Roll/Chord 정보를 확인한다.

## Practice 01 — Cadence
`01-cadence/`의 네 파일을 섞어서 듣는다.

질문:
- 완전히 끝났는가?
- dominant에서 열린 채 멈추는가?
- IV 계열의 부드러운 귀환인가?
- tonic을 예상했는데 다른 chord로 피했는가?

파일: Authentic, Half, Plagal, Deceptive.

## Practice 02 — Major ii–V–I
`02-major-ii-v-i/`에서 block → guide tones → shell voicing 순으로 듣는다.

핵심은 chord note 수가 줄어도 function과 voice leading이 얼마나 유지되는지 듣는 것이다.

## Practice 03 — Minor ii–V–i
`03-minor-ii-v-i/`에서 plain과 altered dominant version을 비교한다. dominant tension이 minor tonic으로 향하는 힘을 어떻게 바꾸는지 기록한다.

## Practice 04 — Tritone Substitution
`04-tritone-sub/`의 original과 substitute를 비교한다.

```text
Original bass: D → G → C
Sub bass:      D → Db → C
```

Guide-tone function과 chromatic bass를 따로 듣는다.

## Practice 05 — Altered Dominant
`05-altered-dominant/`에서 plain G7, b9, #9, b13을 비교한다. '더 복잡하다'가 아니라 tension color와 Cmaj7 resolution을 기록한다.

## Practice 06 — Modal
`06-modal/`의 D Aeolian과 D Dorian을 비교한다. 두 파일의 핵심 비교점은 6th degree다. 같은 D center에서 characteristic tone이 mood를 어떻게 바꾸는지 듣는다.

## 사용 순서
```text
1. MIDI 이름을 가리고 듣기
2. 느낌과 예상 기록
3. Piano Roll 열기
4. Bass 확인
5. 3rd/7th guide tones 확인
6. tension 확인
7. 다시 듣기
8. 직접 한 음을 바꿔 Variation 만들기
```

이 Lab의 목적은 정답률 경쟁이 아니라 `이론 용어 → 실제 청감 → 직접 수정`의 연결을 자동화하는 것이다.
