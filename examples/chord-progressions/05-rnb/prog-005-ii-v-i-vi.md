# Progression 005 — R&B: ii7–V7–Imaj7–vi7

## Harmony
```text
Key: C Major
Roman numerals: ii7 – V7 – Imaj7 – vi7
Chord symbols: Dm7 – G7 – Cmaj7 – Am7
Bars: 4
```

## 학습 포인트
7th chord와 Voice Leading을 공부하기 좋은 진행이다. 코드 이름보다 **공통음 유지와 각 성부의 최소 이동**에 집중한다.

## Variation 과제
1. Triad 버전과 7th chord 버전 비교
2. 각 코드 Top Note가 가능한 한 부드럽게 움직이도록 Voicing
3. Bass Root only와 approach note 버전 비교
4. 70~90 BPM laid-back feel로 Velocity 조정
5. Straight quantize와 약간 뒤로 밀린 comping 비교
6. EP와 clean guitar 계열 음색 비교
