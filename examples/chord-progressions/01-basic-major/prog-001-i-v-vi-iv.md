# Progression 001 — Basic Major: I–V–vi–IV

## Harmony
```text
Key: C Major
Roman numerals: I – V – vi – IV
Chord symbols: C – G – Am – F
Bars: 4
Harmonic rhythm: 1 chord / bar
```

## 왜 공부하는가
기능이 분명하고 반복하기 쉬운 진행이다. 코드 자체보다 Tempo, Voicing, Bass, Rhythm을 바꿨을 때 인상이 얼마나 달라지는지 관찰하는 첫 기준점으로 사용한다.

## 기본 MIDI 입력
각 코드를 4분음표 4개가 아니라 **한 마디 동안 유지되는 Block Chord**로 먼저 입력한다. Root position으로 시작한다.

```text
C:  C E G
G:  G B D
Am: A C E
F:  F A C
```

## Variation 과제
1. 72 / 96 / 120 BPM 비교
2. Root position → 가까운 Voicing으로 수정
3. Bass를 `C–B–A–F`처럼 연결하는 버전 실험
4. Block chord → 8분음표 comping
5. C Major → E♭ Major로 Transpose
6. Piano → EP → Pad로 Render
