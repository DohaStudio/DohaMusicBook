# Glossary

DohaMusicBook에서 사용하는 음악·AI·프로덕션 용어의 canonical definition을 관리한다.

## Initial terms

- Music Intent
- Song Form
- Section
- Energy Curve
- Beat / Tempo / Meter / Feel / Groove
- Key / Scale
- Chord / Chord Function / Harmonic Rhythm
- Reharmonization
- Phrase / Motif / Melody Contour / Range
- Chord Tone / Non-Chord Tone
- Syllable / Prosody
- Arrangement / Timbre / Register / Dynamics / Stereo Image
- MIDI / DAW / Virtual Instrument / SoundFont
- Reference Analysis
- Condition / Candidate / Variation / Regeneration
- Human Review / Candidate Ranking / Similarity
- Mixing / Mastering / LUFS / True Peak
- Copyright / Ownership / Provenance / Lineage

용어 정의는 특정 제품 구현에 종속되지 않도록 작성하고, 구현상 별도 의미가 필요한 경우 Lab 문서에서 구분한다.
